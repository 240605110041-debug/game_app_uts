# Aplikasi Katalog Game Mobile (Game Hub)

Proyek ini dibuat untuk memenuhi Ujian Tengah Semester (UTS) mata kuliah Mobile Programming. Aplikasi ini menyajikan informasi katalog game, kategori, serta spesifikasi sistem minimum yang dibutuhkan.

## 📱 Fitur Utama
- **Halaman Beranda (Home)**: Menampilkan banner sambutan, fitur pencarian, kategori game, daftar Game Populer (Horizontal Scroll), dan Game Terbaru.
- **Halaman Daftar Game (List Page)**: Menampilkan seluruh daftar katalog game menggunakan widget `ListView`.
- **Halaman Detail Game (Detail Page)**: Menampilkan rincian game beserta *Minimum System Requirements* (OS, Processor, RAM, GPU, Storage).
- **Navigasi Interaktif**: Menggunakan `BottomNavigationBar` dan `Navigator.push`.
- **Pengolahan Data JSON**: Menggunakan data dummy JSON lokal yang terstruktur dan siap dikembangkan untuk integrasi REST API.

## 🛠️ Teknologi & Widget yang Digunakan
- **Framework**: Flutter (Dart)
- **Widget Utama**: `Scaffold`, `Container`, `Row`, `Column`, `ListView.builder`, `Card`, `Stack`, `ListTile`, `BottomNavigationBar`.
